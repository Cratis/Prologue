Recipes for the things you'll actually do with Prologue day to day, once [Getting started](../getting-started.md) has shown you the shape of it.

- **[Point Prologue at your system](point-prologue-at-your-system.md)** — pick your capture sources, write `cratis-prologue.json`, and run the Extractor as a sidecar next to a real system.
- **[Running the Workbench](running-the-workbench.md)** — start the Receiver's web interface with Chronicle and MongoDB, and point the Extractor at it.
- **[Workbench walkthrough](workbench-walkthrough.md)** — the seven steps from Systems to Rebuild, which are optional, and how they connect.
- **[Running the Interpreter](running-the-interpreter.md)** — batch mode versus service mode, and configuring LLM refinement.
